# WeatherApp 🌤️

Eine einfache Android-Wetter-App mit aktuellem Wetter und 7-Tage-Vorschau.

## Features

- Aktuelles Wetter (Temperatur, Gefühltes, Luftfeuchtigkeit, Wind)
- 7-Tage-Vorschau mit Niederschlagswahrscheinlichkeit
- Standort-basierte Wetterdaten (GPS)
- Material Design 3 mit dynamischen Farben
- Open-Meteo API (kostenlos, kein API-Key nötig)

## Tech Stack

- Kotlin
- Jetpack Compose
- Material Design 3
- Retrofit + Kotlinx Serialization
- Google Play Services Location
- Open-Meteo API

## Setup

1. Repository klonen
2. Android Studio öffnen (Arctic Fox oder neuer)
3. Sync Gradle
4. Build& Run auf Gerät/Emulator

## API

Daten von [Open-Meteo](https://open-meteo.com/) — keine Anmeldung erforderlich.
